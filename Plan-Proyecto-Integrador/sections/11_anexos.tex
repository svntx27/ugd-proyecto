\section{ANEXOS}

A continuación, se presenta la lista de anexos documentales, legales, técnicos y metodológicos que respaldan la ejecución del presente proyecto integrador:

\begin{description}[font=\bfseries\color{UceBlue}]
    \item[Anexo A:] Formulario Oficial de Aceptación de Tutoría Técnica suscrito por el Profesor Guía / Tutor Académico.
    \item[Anexo B:] Carta Oficial de Entrega del Plan del Trabajo de Titulación a la Dirección de la Carrera de Ingeniería en Ciencias de la Computación.
    \item[Anexo C:] Acuerdo de Confidencialidad, No Divulgación y Tratamiento de Datos Personales (cumplimiento estricto LOPDP Ecuador).
    \item[Anexo D:] Declaración de Autoría, Propiedad Intelectual y Licenciamiento Institucional de Software para la Universidad Central del Ecuador.
    \item[Anexo E:] Diagrama conceptual y esquema entidad-relación normalizado de la Base de Datos Relacional PostgreSQL gestionada mediante el ORM Prisma.
    \item[Anexo F:] Diagrama de arquitectura de software modular desacoplada, servicios API REST en Express.js y estrategia de despliegue sobre plataformas de nube (Vercel y Render).
    \item[Anexo G:] Formato de estructura de las hojas de cálculo Microsoft Excel de la Unidad de Gestión de Doctorados utilizadas como base para la homologación y disociación técnica de datos.
    \item[Anexo H:] Diseño de maquetas y mockups de interfaz para el Panel Administrativo (Next.js 16/Bun), Portal de Usuarios (Astro/Tickets) y sitios de documentación con Fumadocs.
\end{description}
