Este documento detalla los módulos de **Configuración del Sistema (`/api/settings`)**, **Procesos (`/api/procesos`)** y **Diagnóstico Técnico (`/api/tecnico`)**.

---

## 1. Módulo de Configuración (`/api/settings`)

Permite a los administradores calibrar en caliente los parámetros operativos del sistema sin necesidad de reiniciar el servicio Express.

### 1.1 Listar Parámetros Dinámicos

<ApiEndpoint method="GET" path="/api/settings" auth={false} />

Retorna todos los pares clave-valor almacenados en la tabla `system_settings`.

#### Ejemplo de Respuesta (`200 OK`)
```json
[
  {
    "id": "s_1",
    "key": "start_hour",
    "value": "08:00",
    "description": "Hora de apertura de ventanilla UGD"
  },
  {
    "id": "s_2",
    "key": "end_hour",
    "value": "16:00",
    "description": "Hora de cierre de ventanilla UGD"
  },
  {
    "id": "s_3",
    "key": "slot_interval",
    "value": "30",
    "description": "Duración de cada franja en minutos"
  },
  {
    "id": "s_4",
    "key": "system_status",
    "value": "online",
    "description": "Estado general del sistema de citas"
  }
]
```

---

### 1.2 Actualización Masiva en Transacción (`POST /api/settings/bulk`)

<ApiEndpoint method="POST" path="/api/settings/bulk" auth="Bearer JWT" role="ADMINISTRATIVO" />

Actualiza múltiples configuraciones simultáneamente dentro de una transacción atómica `prisma.$transaction()`. Requiere roles `DESARROLLADOR` o `DIRECTOR`.

<ParamTable title="Cuerpo de la Petición">
  <ParamField name="settings" type="Record<string, string>" required={true}>
    Mapa asociativo clave-valor con los nuevos parámetros.
  </ParamField>
</ParamTable>

#### Ejemplo de Petición
```json
{
  "settings": {
    "start_hour": "08:30",
    "end_hour": "15:30",
    "slot_interval": "30"
  }
}
```

---

### 1.3 Exportación de Respaldo de Base de Datos (`POST /api/settings/backup`)

<ApiEndpoint method="POST" path="/api/settings/backup" auth="Bearer JWT" role="ADMINISTRATIVO" />

Genera un volcado completo de la base de datos en formato JSON descargable. Como medida de seguridad avanzada, este endpoint **exige re-autenticación por contraseña**, verificando el hash de la cuenta antes de proceder con el volcado.

<ParamTable title="Cuerpo de la Petición">
  <ParamField name="password" type="string" required={true}>
    Contraseña actual del usuario administrador para re-autenticación obligatoria.
  </ParamField>
</ParamTable>

#### Estructura del Respaldo JSON Descargado
```json
{
  "metadata": {
    "version": "1.0",
    "timestamp": "2026-03-25T14:30:00.000Z",
    "exportedBy": "Administrador UGD",
    "userEmail": "admin.director@uce.edu.ec"
  },
  "data": {
    "roles": [...],
    "permissions": [...],
    "rolePermissions": [...],
    "users": [...],
    "representatives": [...],
    "appointments": [...],
    "settings": [...],
    "facultades": [...],
    "carreras": [...],
    "doctorandos": [...],
    "expedientesDoctorales": [...]
  }
}
```

## 2. Módulos Complementarios

### 2.1 Procesos Universitarios (`/api/procesos`)
- `GET /api/procesos`: Lista los trámites y procesos de posgrado disponibles (requiere permiso `PROCESOS_VER`).
- `POST /api/procesos`: Registra un nuevo trámite (requiere `PROCESOS_CREAR`).

### 2.2 Diagnóstico Técnico (`/api/tecnico`)
- `GET /api/tecnico/health`: Retorna diagnósticos de conectividad a la base de datos PostgreSQL, métricas de memoria y tiempo de actividad del proceso Node/Bun (requiere permiso `TECNICO_ACCESO`).
