El backend de la **Unidad de Gestión de Doctorados (UGD)** está concebido como una API REST desacoplada, moderna y de alto rendimiento desarrollada con **Express.js 5.x**, **TypeScript** y ejecutada sobre el runtime **Bun** (compatible con Node.js 20+). Se conecta a una base de datos relacional PostgreSQL en **NeonTech** mediante el ORM **Prisma 6.4.0** e integra comunicación en vivo para citas presenciales mediante **Server-Sent Events (SSE)**.

Este módulo documental centraliza la arquitectura de software, especificaciones técnicas de endpoints, modelos de datos y guías de desarrollo para que nuevos ingenieros puedan incorporarse, comprender el diseño y escalar el sistema de manera ordenada.

## Ficha Resumen del Backend

| Componente | Especificación Técnica |
| :--- | :--- |
| **Repositorio Local** | `D:\GitHub\Proyecto-Integrador\express-backend-api` |
| **Runtime Principal** | [Bun](https://bun.sh/) v1.2+ (totalmente compatible con Node.js 20+) |
| **Framework HTTP** | Express.js v5.x |
| **Lenguaje** | TypeScript 5.x |
| **Motor de Base de Datos** | PostgreSQL 16+ alojado en **NeonTech** (`aws-sa-east-1`) con connection pooling |
| **ORM** | Prisma v6.4.0 |
| **Seguridad de Acceso** | JSON Web Tokens (`jsonwebtoken`) + Hasheo de contraseñas con `bcryptjs` (salt 10) |
| **Mecanismo Tiempo Real** | Server-Sent Events (SSE) nativo con tipado de eventos y latido periódico |
| **Enrutamiento** | Soporte de prefijo dual (`/api/*` y rutas directas `/*`) y alias de compatibilidad (`/personal-ugd`, `/citas`, `/reservas`, `/labs`) |
